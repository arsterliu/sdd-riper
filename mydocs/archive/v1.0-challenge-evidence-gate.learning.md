## Learning Record

Source Spec: v1.0-challenge-evidence-gate
Trigger: PASS_WITH_CONCERNS review verdict
Observed Problem: 新增门禁函数的测试只覆盖"全部缺失"场景，不覆盖"部分缺失"场景（early-return 模式导致只测到第一个检查点）
Root Cause: validateChallengeEvidence() 使用 early-return 模式（缺 Executed By 直接 return），测试只构造了"全部清空"的 spec，没有单独测试"只有 By 没有 At"和"只有 By+At 没有 Evidence"的场景
Decision Rule: 门禁函数有 early-return 时，每个 return 路径都需要独立测试场景——不能只测"全部缺失"
Applies When: 新增 validate 函数使用 early-return / guard clause 模式时
Does Not Apply When: 函数是单次检查（无 early-return）时
Recommended Action: 为每个 early-return 路径构造独立测试：只缺第一个字段、只缺第二个字段（第一个有值）、只缺第三个字段（前两个有值）
Evidence: Challenge agent 发现 AC-001 的 4 个 scenario 只测了 1 个；补充 3 个测试后 96 tests pass
