## Learning Record

Source Spec:
mydocs/specs/v2.0-cruise-runtime-adapter.md
Trigger:
Execute Log 中出现 BUGFIX：风险扫描把模板注释中的权限、计费、迁移等词误判为高风险。
Observed Problem:
空白或刚创建的 Spec 可能因为模板注释里的高风险词被标记为 `human_required`，导致 cruise run ledger 的 stopReason 不可信。
Root Cause:
`workflow.riskFlags` 直接扫描完整 Markdown 文本，没有先剥离 HTML 注释和模板说明。
Decision Rule:
凡是从模板化 Markdown 推导状态、风险或门禁信号，必须先剥离 HTML 注释；只把用户实际填写的内容作为判断依据。
Applies When:
实现 workflow detector、validate、console index、run ledger 等读取 Markdown 产物并推导机器状态的逻辑。
Does Not Apply When:
需要审查模板自身措辞或生成文档结构时，此时模板注释本身就是目标内容。
Recommended Action:
新增或修改状态推导逻辑时，测试应覆盖空白模板不会误触发风险或完成态。
Evidence:
`npm.cmd test` 通过；`tests/commands.test.js` 覆盖 `sdd cruise --record-run` 的 stopReason。
Related ADR:
无。
Related Artifacts:
src/core/workflow.js; src/core/cruise-run.js; tests/commands.test.js
