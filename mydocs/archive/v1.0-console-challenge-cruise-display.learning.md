## Learning Record

Source Spec: v1.0-console-challenge-cruise-display
Trigger: PASS_WITH_CONCERNS review verdict
Observed Problem: Challenge 对抗审查发现 cruiseRun.readLedger() 返回的 malformedCount 字段被前端渲染函数完全忽略，用户无法感知损坏的巡航记录条目
Root Cause: 前端渲染函数只读取了 count 和 latest，没有读取 malformedCount；后端已传完整数据但前端选择性渲染
Decision Rule: 前端渲染函数必须展示后端传回的所有有意义的诊断字段，特别是表示异常/损坏的计数字段
Applies When: 后端 API 返回包含诊断/异常计数字段（如 malformedCount、errorCount）的数据对象时
Does Not Apply When: 字段仅用于内部调试且对用户无意义时
Recommended Action: 在渲染函数中检查诊断字段，非零时用警告标签展示
Evidence: Challenge agent 独立审查发现此缺口；修复后 cruiseRun 渲染包含 corrupted entries 警告
