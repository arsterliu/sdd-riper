Does Not Apply When: 测试的对象是明确仍处于 draft/active 状态的 Spec，或测试专门验证归档前的迁移过程。
Recommended Action: 归档后运行一次制品路径检索与全量测试；发现活动路径引用时，先确认归档索引和 Spec 的引用路径，再以最小断言修正更新测试。

## Supplemental Rule

Rule: 在 `core.autocrlf=true` 的 Windows 工作区运行本项目全量 Node 测试时，如测试夹具仍以固定 LF 分隔符断言文本，必须在执行日志中明确记录仅用于测试进程的 CRLF→LF 读取归一化预加载；不得将该条件下的结果记为裸 `npm.cmd test`。
Evidence: 独立 Challenge 用裸命令得到 410 PASS、76 FAIL、5 SKIP，首例为固定 LF 断言；使用临时预加载后得到 486 PASS、0 FAIL、5 SKIP。预加载不写工作区，只在 `fs.readFileSync` 返回字符串时将 `\r\n` 归一化为 `\n`。
Applies When: Windows Git 自动换行开启，且测试明确比较模板或制品中的换行符。
Does Not Apply When: 项目已通过 `.gitattributes` 或测试本身完成跨平台换行处理，裸测试命令可稳定通过。
Recommended Action: 在全量验证前先记录 `git config core.autocrlf` 与相关文件的 EOL 状态；若使用临时测试预加载，应记录其文件内容、作用范围和完整调用命令，并在审核结束后删除该临时文件。
