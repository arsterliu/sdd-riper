## Design Note

Approach: 选择本地有界澄清适配，借鉴 grill-me 的决策依赖和推荐答案，不导入其外部运行入口。SKILL.md 默认指向 protocols/clarification.md 与现有派发协议；Plan 内联保留四项要素，按可独立验证变更分步；Archive 仅默认只读检查当前任务事实，完整分支收尾按明确意图触发。
Impact Scope: SKILL.md、INTEGRATIONS.md、REFERENCE.md、README.md、protocols/clarification.md、protocols/subagent-dispatch.md、vendored/superpowers/SYNC.md 和 tests/methodology-routing.test.js。上一任务在 SKILL.md / REFERENCE.md 中的 AC Coverage 修改保留。
Interface / Data Impact: 不变更 CLI 命令、Spec 模型、digest 算法、Provider 或状态机；新增 Markdown 协议通过现有 protocols 打包 / 安装路径分发。无 UI 影响。
Compatibility: 保留七份上游副本及许可证和锁定提交，不修改上游技能原文；四类重复流程降为条件参考而非删除文件。保留现有接入适配的关键句以兼容既有契约测试。
Risks: 主要风险为指导漂移和无意削弱门禁。外部方法不能新增审批、制品或授权，也不能绕过 SDD 原有门禁；auto 仅可在现有授权内自行决定可逆实现细节。默认加载减少不能被表述为免测试、免独立审查或自动归档。现有风险检测因治理文本涉及授权输出 security，设计明确只讨论边界而不更改运行时授权实现。
Test Strategy: 新增精简文档契约测试，锁定默认路由、禁用的重复指令、现有硬规则和安装携带新协议；运行现有接入定向测试、完整 npm test 与 doctor；主 Agent 比较本任务前后 diff / 文件哈希，独立 reviewer 只读审查最终变更。
