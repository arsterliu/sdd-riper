## Learning Record

Source Spec: mydocs/specs/v3.1-console-verification-dogfood.md
Trigger: Execute Log 出现 DEVIATED_MINOR 与 BUGFIX：Windows 上 Playwright webServer 未回收 Console CLI 子进程；新增 Console 测试又被旧 smoke config 意外收集。
Observed Problem: 浏览器断言全部通过但测试进程悬挂；全量 Node 回归随后以 UNKNOWN_AC_TAG 失败，原因是不同验证合同的测试文件共享默认发现范围。
Root Cause: 服务生命周期所有权跨越 Playwright webServer 与 CLI 子进程树，在 Windows 上不够确定；Playwright config 只声明 testDir 而未声明 testMatch，使新增文件自动扩大旧 Provider 的 AC 映射边界。
Decision Rule: 验证夹具必须让资源生命周期和测试发现范围都具有单一、显式所有者。需要创建外部服务或临时项目时，由同一 setup/teardown 记录 PID 与 ownership marker；同一 packageRoot 存在多个验证合同时，每个 config 必须用 testMatch 隔离自己的测试集合。
Applies When: Playwright/E2E 在测试期间启动本地服务、创建临时 Git 项目，或同一 workspace 中存在多个 Provider/config/AC 合同。
Does Not Apply When: 测试不创建外部进程和临时目录，且 packageRoot 只有一个不可扩张的测试合同。
Recommended Action: setup 创建唯一目录和 marker、启动服务并等待 HTTP；teardown 先按 PID 停服再校验 marker 删除目录；禁止按目录年龄清理。为每个 Playwright config 固定 testMatch，并在全量回归中保留原 smoke contract。
Evidence: Console E2E 首次 3/3 断言通过后外层命令 90 秒超时；改由 global setup/teardown 持有 PID 后 3 PASS、8.1 秒正常 exit 0。全量回归首次 254 PASS/1 FAIL（UNKNOWN_AC_TAG），增加 smoke.spec.js testMatch 后 255 PASS/0 FAIL/1 环境 SKIP。
