# Learning Record

## Learning Record

Source Spec: `mydocs/specs/v4.8-workflow-autonomy-policy.md`
Trigger: 三档自治协议迁移后，Windows CRLF fixture、受控事件区块和自然语言风险词分别造成测试搭建、digest 与风险停机的非预期变化。
Observed Problem: 测试 helper 用裸 LF 定位字段会在 Windows 失效；把 Autonomy Control 事件计入 Scope/Plan digest 会使授权写入自身立即过期；仅凭叙述中的“不可逆”等词会覆盖结构化 `Irreversibility: 可回滚` 事实。
Root Cause: 将存储换行、控制面审计元数据和业务风险事实混入了各自不应影响的规范化计算。
Decision Rule: 跨平台制品解析必须接受 CRLF/LF；授权 digest 必须排除其自身受控审计区块；存在结构化风险字段时以字段事实为准，只有缺少结构化事实才允许全文关键词兜底。
Applies When: 新增 Spec 受控区块、内容摘要、跨平台 fixture 或从自然语言提取治理风险时。
Does Not Apply When: 原始字节本身就是合同的不可变制品、附件哈希或安全边界明确要求逐字比较时。
Recommended Action: 为解析器添加 CRLF/LF 双平台用例；为 digest 添加写前/写后稳定性用例；为风险分类添加“叙述提及风险但结构化声明可回滚”的反例，并保持真正破坏性声明仍 fail-closed。
Evidence: `tests/helpers/sdd-fixtures.js`; `tests/commands.test.js`; `tests/autonomy-policy.test.js`; `tests/autonomy-workflow.test.js`; `tests/risk.test.js`; 全量测试 527 项中 522 PASS、0 FAIL、5 个既有 Windows symlink 权限 SKIP。
