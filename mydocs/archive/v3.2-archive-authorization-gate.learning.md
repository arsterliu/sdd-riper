## Learning Record

Source Spec: mydocs/specs/v3.2-archive-authorization-gate.md
Trigger: 完成状态被投影为 archive 动作，且不可逆命令缺少独立授权门禁。
Observed Problem: 自主 Agent 可能把完成就绪误读为执行许可；即使后续门禁拒绝，过早创建目录也会留下副作用。
Root Cause: 同一个 archive_ready 字段同时承担质量事实、路由动作和权限暗示，且授权校验没有被设计为写路径的第一道前置条件。
Decision Rule: 完成就绪、下一步路由与副作用授权必须建模为三个独立概念；不可逆命令的授权校验必须先于 mkdir、write、unlink、append 等任何副作用，并且 force 不能绕过授权。
Applies When: 本地 CLI、迁移、删除、发布、归档或其他由 Agent 触发的不可逆/高影响操作需要人类许可时。
Does Not Apply When: 纯只读分析、可安全重复且无外部副作用的查询操作。
Recommended Action: 状态层输出 request_*_authorization；执行命令要求本次调用的一次性结构化授权与证据；Agent 协议要求停止询问当前用户且禁止自行构造；失败测试对完整状态树做零写入快照断言。
Evidence: tests/commands.test.js 的缺失/非法/force/not-ready 场景先 RED，修复后证明 exit 2 或 not-ready 均不改变目录树；tests/state-matrix.test.js 证明完成状态只路由到 request_archive_authorization。
