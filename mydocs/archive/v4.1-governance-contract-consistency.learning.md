## Learning Record

Source Spec: mydocs/specs/v4.1-governance-contract-consistency.md
Trigger: Execute Log 中出现 DEVIATED_MINOR 与多次 BUGFIX，且全量回归与独立复审暴露了历史兼容和受控文本融合的边界条件。
Observed Problem: 为新增活动制品规则收紧判断时，未标注来源的旧快照可能被误判为归档而跳过 fail-closed；为刷新 AI 受控区块而仅凭宽松文本特征识别生成内容时，损坏 marker 中的用户文本可能被覆盖。
Root Cause: 将“缺少位置字段”错误地等同于“非活动”，以及把可读提示文本当作可靠所有权标记，而不是只在明确的归档路径或字节级确认的生成区块上放宽行为。
Decision Rule: 兼容放宽必须由明确状态触发：仅 `location === archive` 可跳过活动 Provider readiness；受控文本仅在单一完整 marker 对或字节完全匹配当前生成块时原位刷新，其他损坏/多重 marker 一律保留原文并追加新块。
Applies When: 对历史制品、可选状态字段、旧调用方快照、追加式配置融合、可重复生成的 Markdown/AI 指令块进行契约收敛时。
Does Not Apply When: 调用方已提供可验证的明确身份或归档状态，且该状态本身就是当前公共契约的一部分；此时可按该状态的既有规则处理。
Recommended Action: 先为明确路径、缺省路径、损坏 marker、伪签名用户文本和第二次执行建立回归测试；再以最窄的正向条件实现宽容路径，避免用否定条件或模糊文本特征推断所有权。
Evidence: tests/state-matrix.test.js 覆盖 archive/active/缺省 location；tests/verification-cli.test.js 覆盖 freshness blocker；tests/governance-contract.test.js 覆盖四类 AI 配置、损坏/多重/伪签名 marker 与二次 init 幂等；npm.cmd test 最终为 441 PASS / 0 FAIL。
